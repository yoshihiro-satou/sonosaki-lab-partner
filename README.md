# sonosaki-lab / partner page

[**sonosaki-lab.com/partner**](https://sonosaki-lab.com/partner) のソースです。
Web 制作会社さま向けに「実装だけ引き受けます」とお伝えするための1枚で、
**読み手が実装者を審査する側**であることを前提に作りました。

実際に動いているページを見てから、このコードを読んでいただくのが早いと思います。

---

## なぜソースを公開しているか

このページを見る方は、たいてい**デベロッパーツールを開きます。**
であれば、画面の見栄えより**作り方の判断**を見てもらったほうが早い、と考えました。

そこで2つやっています。

1. **本番の HTML にも解説コメントを残している**（View Source でそのまま読めます）
2. **このリポジトリを公開している**（JSX のコメントは本番ビルドで消えるため）

コメントの方針は1つだけです — **何をしたか、ではなく、なぜそうしたかを書く。**
差分を見れば何をしたかは分かるので、残す価値があるのは判断のほうだけです。

## 使っているもの

Next.js 16（App Router）/ React 19 / TypeScript / CSS Modules /
GSAP（ScrollTrigger）/ Lenis / Cloudflare Workers

**画像は0枚**、**日本語 Web フォントは0KB**（OS 標準のゴシックのみ）。
線・余白・組み方・動きだけで作っています。表示速度を売っているページなので、
飾りで重くすると主張が崩れるためです。

## 4つの動きと、そこで守ったこと

**① 幅を引ける枠**（最初の画面）
「レスポンシブ対応できます」と書く代わりに、**相手の指で確かめてもらう**ための仕掛けです。
中のカードはメディアクエリではなく **Container Queries** で組み替わります。画面幅で判定すると、
枠を引いても中身が変わらず、仕掛けとして成立しないためです。
幅は絶対座標で出しています。差分を足し込むと、取りこぼした 1px が積もって指とズレていきます。

**② 節見出しの一文字ずつの立ち上がり**
🔴 **最初の画面には掛けていません。** そこが LCP（最大要素の表示）になるので、
隠してから出すと計測が動き終わりを待ち、モバイルのスコアが素直に落ちます。
**演出を入れるかどうかより、どこに入れないかを決めるほうが効きます。**

**③ スクロール連動の線画**（SVG・約2KB）
画像なら 40〜80KB かかります。線の全長は `getTotalLength()` で実物から測っています。
手で数字を書くと、線の形を少し直しただけで動きが途中で止まるためです。

**④ 事例の切り替え**（View Transitions）
CSS のフェードだと「古い絵が消えて新しい絵が出る」だけで間がつながりません。
非対応のブラウザでは呼ばずに素の更新へ落とします。呼べば例外で落ちて、
切り替え自体が動かなくなるためです。

## 壊れ方を軽いほうに倒す

このコードで一貫させていることが1つあります。

> **隠す指定を CSS に書かない。**

一文字ずつの立ち上がりも、ふわっと出るリストも、初期状態（隠れた位置）を CSS に持たせていません。
JavaScript が「これから動かせる」と確かめた後に、はじめて隠します。

CSS で隠してしまうと、**JS が落ちた端末で中身が永久に出ません。**
このページで消えるのが「お引き受けできること・できないこと」だと、
読み手は仕事の範囲が分からないまま帰ることになります。演出のために本題を失うのは本末転倒です。

何も起きなければ、**ただの読める一覧として残る** — そこを起点に組んでいます。

同じ考えで、`prefers-reduced-motion`（動きが苦手な設定）のときは
**GSAP も Lenis も1バイトも読み込みません。** 0KB で、最初から出来上がった状態が出ます。

## 色の決め方

配色は参考にした絵から**画素を読んで**決めています（目分量で拾っていません）。
そのうえで、**コントラスト比を WCAG 2.1 の相対輝度で実測**してから採用しました。

| | 対 地 #16316f |
|---|---|
| 本文 `#eaf0ff` | 10.81:1（AAA） |
| 補助文 `#a8bbe4` | 6.40:1（AA） |
| 差し色の金 `#f5c445` | 7.55:1（AAA） |
| 金の面にのせる字 `#0e1f4a` | 9.79:1（AAA） |

斜めストライプの明暗差は **1.115:1**。あるのは分かるが字の邪魔をしない幅に抑えています。
暗い帯の上では補助文が 6.40 → **7.13:1 に上がる**ので、可読性は落ちません。
